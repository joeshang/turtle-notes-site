GOOD TO KNOW

落笔之前，
你可能还想知道。

关于两款 App、内容归属与开始使用。

为什么叫「龙龟」？+

我的孩子特别喜欢小乌龟，所以起名时，我也想让这个写作工具和小乌龟有一点联系。后来想到龙龟又叫赑屃，有驮碑载文的寓意，于是就用了「龙龟」这个名字，也有了「龙龟载文，落笔成章」这句话。

它是原生 Markdown 应用吗？+

是。macOS 使用 AppKit，iOS 使用 UIKit，Markdown 正文采用原生文本渲染与编辑，并使用系统窗口、菜单和文本交互，不使用 Electron 承载整个应用。公式与图表由相应的专用渲染组件处理。

龙龟笔记和龙龟编辑器，该选哪一个？+

如果你想长期积累笔记、使用标签和双向链接，选择龙龟笔记；如果你希望直接打开并编辑独立 Markdown 文件，选择龙龟编辑器。两款 App 可以独立使用，也可以同时安装。

内容存在哪里？可以离线使用吗？+

两款 App 均可离线编辑。龙龟笔记将笔记与附件保存在本地笔记库，具备云端权限的龙龟笔记版本可选择开启 iCloud 同步；龙龟编辑器将文稿保存到你选择的文件位置，不使用 Notes 笔记库或内置 CloudKit 同步。

支持哪些 Markdown 内容与导出格式？+

两款 App 共用 Markdown 编辑能力，支持标题、任务清单、表格、公式和 Mermaid，可切换渲染与源码视图，并支持 Markdown 及引用的本地附件、PDF 导出。

支持哪些设备？现在可以下载吗？+

龙龟笔记 macOS v1.2.1 已发布，适用于 Apple Silicon Mac（macOS 14.0 或更新版本）；龙龟编辑器 macOS v1.2.1 已发布，适用于 Apple Silicon Mac（macOS 14.0 或更新版本）。点击首页的 macOS 下载按钮可进入统一下载页，选择相应安装包。龙龟笔记另有 iPhone 与 iPad 版本，需要 iOS 18.0 或更新版本；iOS 版公开下载仍在准备中。

需要注册龙龟账号吗？+

当前两款 App 没有龙龟账号系统。使用本地编辑功能不需要注册；可用版本中的 iCloud 同步使用设备上已登录的 Apple 账户。
